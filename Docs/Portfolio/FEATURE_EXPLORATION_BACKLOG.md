# 구현 탐색 백로그

## 목적

RODI에 바로 도입하기로 확정한 로드맵이 아니라, 제품 적합성과 기술 학습 가치를 검토한 뒤 구현해보고 싶은 기능을 기록한다.

## 주행 경험

- [ ] 코스 진입·완료 로컬 알림
  - 코스에 진입했을 때와 코스 주행을 완료했을 때 각각 로컬 알림을 한 번 표시한다.
  - Live Activity가 진행 상태를 표시하는 동안에도 놓치기 어려운 중요 상태 전환으로 안내한다.
  - 알림 권한이 없을 때의 동작과 같은 상태의 중복 알림 방지를 함께 검증한다.
- [ ] 음성 안내 TTS
  - 외부 길안내 앱의 음성과 최대한 겹치지 않도록 안내 시점과 오디오 정책을 먼저 정한다.
  - 코스에 진입했어요! 진행 상황을 계속 알려드릴게요.
  - 코스의 약 10%를 주행했어요!
  - 코스의 약 50%를 주행했어요!
  - 코스 주행을 완료했어요. 후기를 작성해 주세요!
  - 같은 진행 구간의 중복 발화 방지와 백그라운드·화면 잠금 상태를 함께 검증한다.

## Apple 플랫폼 확장

- [ ] CarPlay 적용 가능성 탐색
  - RODI에서 제공할 사용자 가치와 기능 범위는 아직 정하지 않았다.
  - 지원 가능한 앱 범주·Entitlement·템플릿 제약을 확인한 뒤 후보 기능을 정한다.
- [ ] watchOS·WatchConnectivity
  - 진행 상황 확인, 햅틱 알림, iPhone과의 상태 동기화 중 어떤 문제를 해결할지 먼저 정한다.
- [ ] WidgetKit
  - 추천 코스, 최근 연습 기록, 재개 가능한 흐름 중 위젯에 적합한 정보를 먼저 정한다.
  - Live Activity와 중복되지 않는 역할을 정의한다.

## 수익화

- [ ] 광고
  - 운전 중인 사용자 흐름에는 노출하지 않는 것을 전제로 위치·빈도·사용자 경험 영향을 검토한다.
- [ ] 결제
  - 판매 대상이 디지털 기능인지 실물·외부 서비스인지 먼저 정의하고 적합한 결제 방식을 검토한다.

## 데이터 규모와 미디어

- [ ] 대규모 목록
  - 페이지네이션, 중복 제거, 취소와 최신 응답 판정, prefetch, 메모리 사용량을 검증할 수 있는 시나리오를 만든다.
- [ ] 이미지 캐시
  - 메모리 캐시와 디스크·HTTP 캐시의 역할, eviction, 메모리 경고, 동일 요청 병합을 다룬다.
- [ ] 미디어 재생·처리
  - 원격 영상 재생, buffering, 썸네일, 재생 상태 복구처럼 구현할 문제를 먼저 구체화한다.
  - YouTube 영상 삽입은 외부 플레이어 연동이고, AVFoundation을 이용한 직접 재생·편집·인코딩은 별도 기술 범위로 구분한다.

## 시작 전 확인

각 항목을 구현하기 전 다음 내용을 짧게 확정한다.

- RODI 사용자에게 해결해 주는 문제
- 기존 기능과 겹치지 않는 역할
- 필요한 권한·Entitlement·서버 변경
- iOS 16.1 지원 가능 여부
- 개인정보·운전 중 방해 가능성
- 자동 테스트와 실기기 검증 기준
